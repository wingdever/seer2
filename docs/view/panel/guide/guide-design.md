## 0. 一句话目标

**在 `#/map` 点 HUD 底栏「指引」钮 ⇒ 弹 570×400「疑难指引」窗：三颗可切页签（属性攻击 / 属性防守 / 性格查询）用 23×23 相克表与 55 性格表作答；第四颗「新手指引」= 诚实提示 `Noob` 面板待建（本面板不关）；关系区不照搬上游 12 槽静默截断，`精灵王` 的 22 / 21 项全部可达；性格页只做发行版实际可见的 55 行列表，并补表头 / 选中反馈 / 底部说明。全面板只读、零写档、零新 L1。**

**「疑难指引」解决的是"玩家查表"**：我打谁克制、谁打我克制、某性格加什么减什么。它不产出任何游戏状态，也不改任何存档字段。

## 3. 目标行为（真值）

### 3.1 面板生命周期（GD1）

1. **开**：`#/map` 内点 HUD `guide` 钮 ⇒ `openPanel('rb-guide', …)`（A2 同名去重）；NPC `openPanel GuideLine[...]` 走同一入口（L4 分派器加一条分支）。
2. **单例**：面板已开 ⇒ 再点不叠层（宿主同名去重，旧层销毁、新层打开；页签/选中态回到默认）。
3. **默认页 = 属性攻击**（对位 `defaultSelect:1`；游标初始落在「属性攻击」）。
4. **页内记忆**：同一面板生命期内切页再切回，属性攻击/防守两页各保留自己的选中属性（对位两套独立 controller/model）。
5. **关**：右上 Esc 图 / 遮罩点击 ⇒ 关闭；**不监听全局 Esc 键**（同 worldmap/spt/activity 先例，面板层不私加键盘层）。
6. **零副作用**：开/关/切页/点属性/点性格/滚列表**都不写盘**，不碰 `session.data`、不调 `A.save()`；本面板没有写动作。

- 标题线 `[195,90,570,23]` = `Panels/ItemShop/Sprites/title line.png`（在盘）。
- 标题「疑难指引」24px、`#52e5f9`、水平居中（上游 TMP `[300,67,360,50]`）。
- Esc `[725,75,35,35]` = `Sprites/Game/Hint Box/Green Esc.png`（在盘；`mountImg` 缺图自陈，不伪造）。

### 3.3 页签机器（GD3）

- 四颗页签全画出、可点，位置/尺寸照预制：`新手指引 [250,130,100,30]`、`属性攻击 [370,130,100,30]`、`属性防守 [490,130,100,30]`、`性格查询 [610,130,100,30]`；18px。
- **游标**（`Panels/OldPetBag/Sprites/269.png`，`[370,129,100,32]`）：只跟随三颗可切页签（`left = 175 + page×120`，相对窗），**不停在「新手指引」**（对位 `optionRects` 只有 3 项）。
- 点三颗可切页签 ⇒ 立即切页；当前页签文字提亮（游标之外的第二重可读性，零新逻辑）。
- **「新手指引」= 跳转钮，不是第四页**：本批 `Noob` 面板未建 ⇒ 点击 `openHintbox` 诚实提示（「新手指引面板（Noob）待建：独立面板线，含四步进度与新手判定」），**本面板保持打开、页签不变**（GDQ1；对位报告 A13 上游"先关本面板"的行为**不照搬**，因为目标面板不存在）。

### 3.4 属性页版式与选择（GD4）

- 左格：23 个属性按钮，**5 列 × 5 行、末行 3 颗**，40×40 盒 + 30×30 真图标（`_kit.elementIcon`，23/23 在盘）；顺序 = 元素 id 0..22 行主序。
- 坐标照预制：格 `x = 208+44c`、`y = 200+44r`（绝对），相对窗即 `left = 13+44c`、`top = 130+44r`。
- 选中格加青色描边/光晕（可读性；上游选中态由按钮自身 SpriteState 表达）。
- **不画 Prev/Next 与页码**：上游 `lastPage=0`、两键不可交互、页码文本未绑（报告 A4）——画出来就是伪造可翻页。GD4 直接省掉这组死 UI。
- **页签名即模式**：攻击页三区标题「克制 / 微弱 / 无效」，防守页「被克制 / 被微弱 / 被无效」。
- 关系区标题左侧显示**当前选中属性**的图标 40×40 + 名称，名称 = `getElementName` + **补「系」**（「普通系」「草系」…；对位预制占位文本，登记为显示层偏差，报告 A7/GD5）。

### 3.5 攻击页语义（GD5）

- 数据 = `getAttackRelation(e, filter)`：遍历 **23 个防守方**，取 `ELEMENT_DEFENSE_RELATION[防守方][e]`（**列**）。
- 三区：`>1` ⇒ 克制；`0<v<1` ⇒ 微弱；`==0` ⇒ 无效。
- 例：草系攻击 ⇒ 克制 水/地面/光，微弱 草/火/飞行/虫/毒(特质)/龙/圣灵/精灵王/上古/机械，无效 无。
- 脚注：「**克制**表示伤害2倍  **微弱**表示伤害0.5倍」（「克制/微弱」红色强调），逐字对位攻击页 TMP。

### 3.6 防守页语义（GD6）

- 数据 = `getDefenseRelation(e, filter)`：直接筛 `ELEMENT_DEFENSE_RELATION[e]` 这一**行**，返回攻击方 id。
- 三区：`>1` ⇒ 被克制；`0<v<1` ⇒ 被微弱；`==0` ⇒ 被无效。
- 脚注：**不复用攻击页那句**（报告 A6 上游逐字复制导致语义错位）⇒ 目标文案「**被克制**表示受到伤害2倍  **被微弱**表示受到伤害0.5倍」。

### 3.7 关系区不截断（GD7 · 对位报告 A5）

- **不照搬**上游 12/12/1 槽位 + `i >= result.Count` 隐藏的静默丢弃（决议 ②：上游代码逻辑缺陷，声明后写无该缺陷的目标行为）。
- 区几何保持预制占位：`克制 [435,220,120,190]`、`微弱 [565,220,120,190]`、`无效 [695,220,50,190]`（相对窗 `left 240/370/500、top 150、width 120/120/50、height 190`）。
- 区内布局：标题行（区名 + **数量**，如「克制 22」）高 22；下方**可竖向滚动**的槽区（高 166）。按钮 **36×36**、图标 **30×30**、**3 列**（无效区 1 列），行距 38。
- 数量 = 列表长度（视图只显示内容层给的数组长度，不做游戏算术）；`精灵王` 攻击克制 22、防守被微弱 21，**全部可达**（滚动即可）。
- 空区显示「—」（而非空白），滚动条用细窄暗色（同面板色调）。
- 备选（不采用）：缩成 3×8 全塞下（图标 <20px 不可读）/ 保留 12 槽截断（丢 10/9 项）/ 把溢出项再分页（伪造上游不存在的翻页交互）。

### 3.8 性格查询页（GD8 · 对位报告 A8–A12/A14）

- **只做发行版实际可见的列表**：55 行（`Personality` 0..54，声明顺序），不做 `Table` 25 格、不做关系图、不复活上游 `Note` 死块。
- 列表区：`[227,220,510,230]` 附近的滚动视口；**固定表头**在视口上方：`性格 | 物攻 | 特攻 | 物防 | 特防 | 速度`（6 列；列宽 `100 + 82×5 = 510`）。
- 每行 35px：姓名（青色）+ 5 格。
  - 格值 = `getPersonalityBuff(id)` 相对 1 的增量 ⇒ 显示 **`+10%` / `-10%` / `-`**（`>1` 绿、`<1` 红、`==1` 灰白），**不显示乘数原值 `1.1`/`0.9`**（报告 A10）。
  - **不画体力列**：`getPersonalityBuff` 的加/减索引只落在 0..4，体力恒不变（报告 A9）；上游 Hp 列本就隐藏且与 Name 重叠。
- **点击行 = 选中**：行高亮；底部说明条显示 `getPersonalityBuffDescription(id)`（如「物攻+10% 速度-10%」；两段用空格连接，单行 12–13px）。默认选中第 0 行（实干），开页即有说明。
- 55 行 × 35 = 1925px 内容高，竖向滚动；滚动条细窄、青色 Handle（对位上游 Scroll View 口径）。
- 不显示 55 条之外的性格（性格 id 越界 ⇒ 数据层不给行）。

## 7. 复核项（GDQ1–GDQ3 · 建议默认已落码，非阻塞）

> 本线为人类点名开工特例；以下三项**已按建议默认落码**。人类复核时若选备选，按"改选后果"回改（只需回一个词，如「GDQ2 选 A」）；不回复则保持默认。

### GDQ1「新手指引」这颗钮怎么处理？

- **这是什么**：面板左上角那颗页签「新手指引」。上游点它 = **关掉疑难指引、另开一个新手面板（Noob）**；新手面板要读四步新手进度和"是否新玩家"，是另一条面板线，本批没建。
- **为什么现在要问**：不处理的话，要么画一颗点了没反应的死钮（玩家会以为坏了），要么把本面板关掉后什么都没有（更糟）。**不定住会让"指引"面板四颗钮里有一颗是坑。**
- **选项与后果**：
  - **A（默认）保留钮 + 诚实提示**：点了弹提示"新手指引面板（Noob）待建"，疑难指引**不关**。后果 = 玩家知道这里将来有内容，当前不崩、不丢上下文。
  - B 隐藏这颗钮：只剩三页，界面干净，但上游的四钮布局少一颗、玩家不知道有新手指引。
  - C 现做最小 Noob 页（四步进度 + 领取）：**跨线**，要读 `Activity.Noob` 与 `Player.IsNoob()`，工作量与风险都超出本面板。
- **建议**：A。**你只需回**：默认即可，或「GDQ1 选 B/C」。

### GDQ2 关系区装不下时怎么办？

- **这是什么**：属性页右侧三个关系区（克制 / 微弱 / 无效）上游每块只能摆 12 / 12 / 1 个图标。实测 23 属性里 **只有「精灵王」装不下**：攻击时克制 22 个（少显示 10 个）、防守时被微弱 21 个（少显示 9 个）。上游是**静默丢掉多的**，玩家看不到。
- **为什么现在要问**：这是发行数据里真实可触发的缺口（选精灵王就发生）；照搬 = 我们把上游 bug 一起搬进来，不照搬就得定一种"怎么装下"的交互。
- **选项与后果**：
  - **A（默认）区内滚动 + 标题带数量**：外观尺寸不变，鼠标滚轮/滚动条看全 22 / 21 项，标题直接写「克制 22」。后果 = 信息不丢，代价是多一次滚动。
  - B 照搬截断：和上游一模一样，但精灵王的 10 / 9 个目标永远看不到。
  - C 缩小图标硬塞：3×8 全塞进 120×190，图标要 <20px，几乎不可辨。
- **建议**：A（决议 ②：上游代码逻辑缺陷声明后不照搬）。**你只需回**：默认即可，或「GDQ2 选 B/C」。

### GDQ3 性格页做到什么程度？

- **这是什么**：性格查询页。上游发行版里能看见的只有一张"性格名 + 5 列百分比"的裸表：表头、选中反馈、说明文字、关系图、25 格表格在预制里都被关掉了；而且数字显示的是 `1.1`/`0.9`，不是 `+10%`/`-10%`。
- **为什么现在要问**：只照抄裸表会很难用（不知道列是什么、点了没反馈）；把死 UI 全复活又要 20 张缺失的关系图（55 张只有 35 张在盘）。
- **选项与后果**：
  - **A（默认）列表 + 表头 + 选中 + 底部说明**：55 行，表头写明六列，点行高亮并在底部显示"物攻+10% 速度-10%"；数字显示 `+10%`/`-10%`/`-`。后果 = 好用、不碰缺失素材；代价 = 与上游裸表外观不完全一致（上游那几块本就不可见）。
  - B 逐像素照抄裸表：没有表头/说明/选中，数字是 `1.1`，最"像"上游，但查询体验差。
  - C 复活关系图 + 25 格表：**20 张图缺失**、25 格上游无绑定，等于自造内容，违背"缺图不伪造"。
- **建议**：A。**你只需回**：默认即可，或「GDQ3 选 B/C」。
