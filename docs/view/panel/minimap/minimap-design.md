## 0. 一句话目标

**在 `#/map` 场景点 HUD 的小地图钮 ⇒ 按"当前图的 `category`"弹对应的自绘小地图面板（11 块之一）：底图 / 路线图 / 节点点 / 标题条 / 每区线稿图标 + 区名**全部照报告 §4.1 的绝对像素坐标摆上游 PNG**；点区 = 发 `teleport{mapId}` 决议 ⇒ 走既有 `teleport` sink 换图；**该类目没有面板（77/272 张图 = 28%）⇒ 弹提示盒"该区域暂无小地图"、不弹面板**（不照搬上游"一律回退飞船图"的 A1）。**

## 1. 范围与边界

| 归本份 | 不归本份 | 支点 |

| 11 块面板的**形状 / 图层 / 热区表 / 关闭 / 传送接线**目标行为 | **大地图（WorldMap）面板** | 已落，`docs/view/panel/worldmap/` |
| 缺类目（22 类目里 11 个有面板）⇒ **提示不弹** | **给缺类目现画一张小地图** | 【设计】不做：无美术源、无真值表，编出来就是伪造 |

## 2. 上游真值摘要（细节不重复，见报告）

- 入口 = `Map.unity` 唯一一处 → `MapWorldController.OpenMiniMapPanel()` ⇒ `Panel.OpenPanel("MiniMap" + categoryId)`，`null` ⇒ **回退 `MiniMap1`**【报告 §1 / A1】。
- 11 块面板 = `MiniMap{1,2,3,4,5,6,7,9,11,12,100}`，**22 个类目里只有 11 个有面板** ⇒ **77/272 张图（28%）无面板**【报告 §2.2】。
- **113 个热区**（96 `Minimap Region` + 8 `ShipMapBlock` + 9 内联 `Button`）= **112 个不同目的地 + 1 个 `mapId=0`**，**悬空 0**【报告 §4】。
- 出路 = `Module.GoToMap(mapId)` ⇒ `TeleportHandler.Teleport(mapId)`，**无门禁、无两步走位**【报告 §4】= 与大地图**同一终点**。
- 画面 = 底图 / 路径图 / `spot.png` 节点点 / `map title.png` 标题条 / 每区一张**青色线稿图标** + 上方 `Title` 文字【报告 §3】。
- **面板 ↔ 类目闭环【实测，本份补记】**：11 块面板的 **112 个目的地逐个回查 XML 根节点 `category`** ⇒ **每块面板的目的地全部落在自己那个类目里**（`MiniMap2` 的 13 个全是 cat2、`MiniMap100` 的 8 个全是 cat100…，**0 跨类目**）；112 个目的地**逐个都有中文 `name`**（缺名 = 0，含 8 个负 id 飞船舱）。⇒ "从当前图的类目弹对应面板、面板只送你去本类目"这件事在上游就是自洽的，我方**不需要**为跨类目跳转设计任何规则。

## 3. 目标行为（真值）

### 3.1 面板生命周期（MM1）

1. **开**：`#/map` 内点 HUD `rbh-minimap` ⇒ 读当前图 `category`（桥字段 `rec.category`，`game/logic/map/parse-map.js:296`）：
   - `category ∈ {1,2,3,4,5,6,7,9,11,12,100}` ⇒ `host.openPanel('MiniMap'+category, …)`（A2）弹**对应那块**面板；
   - **否则 ⇒ 弹提示盒"该区域暂无小地图"（A3 `openHintbox`），不弹任何面板**【设计：修 A1，**不照搬回退**】。
2. **无翻页**：一块面板 = 一屏（上游也没有翻页，报告 §2 表第 2 行）。
3. **关**：✕ 钮（面板内 `Esc Button` 位）/ 遮罩点击 / ESC（宿主栈口径，A2）；关闭 ⇒ 游戏状态**零变化**（面板不写档）。
4. **栈纪律**：在 `#/map?slot=N&map=…` 上弹层，**不改 URL、不进历史**；传送发生时才经 `gotoMap(…, pushHist)`（`AGENTS.md §3` 战斗回图带槽纪律不变）。

### 3.2 画面（MM2）

- **图层照搬**：报告 §4.1 每张表的"图层"段 = 面板框内的绝对像素矩形，**逐个 `<img>` 摆上去**（顺序 = 表内顺序，后摆的盖先摆的）；面板框 = 该块自己的 `w×h`（720×420 或 710×440），**在 960×540 逻辑画布里居中**（上游内层 `Panel` 就是居中摆，报告 §2 表末行）。
- **热区照搬**：每区 = 一个可点方块（报告表的"热区矩形"），方块里画**该区的线稿图标**（"图标"列，拉伸到热区矩形 = 上游同做法，报告 §3 末段"27 个被拉伸"照做）；**图标缺 override 者用 prefab 默认**（只有 2 处，报告 §3 末段）。
- **区名**：热区上方"标签框矩形"处画 `Title` 文字（120×25、字号 16、白字带描边、居中）；**文字取报告表的"显示名"列**，其中 `MiniMap12` 的两条**尾换行清洗掉**（修 A9）。
- **裁剪【设计】**：面板框 `overflow:hidden` ⇒ 报告 **A7** 的溢出（`MiniMap7` 的 1920×1120 大图、标题条压出框顶 3px、`MiniMap100` 底图非等比压扁）**不照搬**：图仍按上游矩形摆，但**超出框的部分裁掉**（`MiniMap100` 的底图仍按 710×440 摆 = 与上游一样压扁，因为它上游就是整幅底，不压就出框）。
- **青色乘色【设计】**：上游热区 `Image` 带 `rgba(0.32,0.90,0.98,1)` 乘色（报告 §3 末段）；素材本身已是青色线稿 ⇒ **我方不再乘色**（乘了只会更暗），**MQ3**。
- **不画的东西**：`MiniMap9` 那 22 个 `active=0` 的装饰点（A6）不画；上游隐藏的东西我们不让它显形。

### 3.3 传送链（MM3）

1. 点热区 ⇒ 发 `teleport{mapId}` intent，走**与大地图 / 光口 / NPC 对话出路同一台** `resolve→run` 机的**同一个 sink**（`mapScene.js makeRunCtx.teleport`，MB5 已落；大地图 WM-b 已接同一处）。
2. `session.decideTeleport(mapId)`：`0 ⇒ notOpen` ⇒ **弹提示盒"地图暂未开放"**（上游靠 `TeleportHandler` 内部，我们保留同等可观察行为；本族只有 `MiniMap100` 的 `Lonely` 一个 `mapId=0` = 修 A5 / **MQ4**）；非 0 ⇒ `gotoMap(String(mapId), true)`（现场解析、不缓存，`AGENTS.md §4.9`）。
3. 面板在传送执行**前关闭**（同大地图 §3.3 第 3 条 / MB6 对话浮层口径）。
4. **不做**：Mod 面板分支（§1）；**不做**：给不可点的东西编传送语义 —— **能点的才点**（人类 2026-10-19 拍板）：`spot.png` 节点点、标题条、底图**都不可点**，只有报告 §4.1 列出的 113 个热区可点。

### 3.4 当前图高亮（MM4）

- 热区 `mapId == session.currentMapId` ⇒ 标"**在此**"（同大地图 WM2 口径）；**不禁止再点**（同图再点 = 重进，同上游 `Teleport` 行为）。
- 夜图（负 id）与飞船舱（`-10…-80`）同样能命中高亮（本族目的地里就有 8 个负 id）。

### 3.5 悬停（MM5）

- 鼠标悬在热区上 ⇒ 在**指针右下**显示一个小提示（内容 = 报告表的 `hover` 文案，即上游 `SetInfoPromptText` 的那串）；移出即隐。
- **不伪造**：报告 **A3/A4** 里"没有提示文案"的热区（`MiniMap1` 的 8 个舱室、`MiniMap100` 的 `Lonely`）⇒ **不出提示**（上游同样不出）。
- ⚠️ 上游的提示是"跟随鼠标的黑底白字自动尺寸盒"（`InfoPrompt.cs`）；我方 = **DOM 小气泡**，样式自绘最小 UI（正式排版归 A3）。

### 3.6 不变量

- **MM1** 面板零写状态：开 / 关 / 悬停不产生落盘（Save 面只在传送换图时按既有链走）。
- **MM2** 热区表是**唯一内容真值**：11 块面板的图层与热区以报告 §4.1 为准，改表先改报告/本份，**不许**运行时"从地图数据里现编目的地"（`maps.json` 全 272 图 ≠ 目的地集合）。
- **MM3** 传送只经 `teleport` sink 一条链：面板**不直接**碰 `gotoMap` / `location.hash`（依赖方向 View→M5 决议，不旁路；同大地图 WM3）。
- **MM4** 类目 → 面板**一对一**：`MiniMap{category}` 只服务自己那个类目；**缺面板 = 提示、不回退、不复用别块面板**（修 A1）。
- **MM5** L4 自绘、**零新素材**（全部吃盘上既有 Unity PNG）、零第三方：与 A2/A2b/B3/MB6/WM 同族的**围栏再扩一格**（`AGENTS.md §4` 第 11/12/14 条先例），**不碰 `MapRunner.as`、不重编译 AS3**；正式美术仍归 A 组。
