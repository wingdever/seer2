## 0. 一句话目标

**在 `#/map` 场景点 HUD 地球钮 ⇒ 弹一个自绘的最小"世界地图面板"：两页（阿卡迪亚星 / 新世界）、37 个目的地块（照报告 §3 真值表）、点块 = 发 `teleport{mapId}` 决议 ⇒ 走既有 `teleport` sink 换图；`mapId=0` 的块给"暂未开放"。**

## 3. 目标行为（真值）

### 3.1 面板生命周期（WM1）

1. **开**：`#/map` 内点 `rbh-globe` ⇒ 经面板宿主 `host.openPanel('WorldMap', …)`（A2）弹面板；**初始页 = 当前图 `worldId`**（桥 `rec.worldId`；夜图负 id 同公式）。
2. **翻页**：`上一页/下一页` 两页循环（模 2，同上游）；页标题 = `阿卡迪亚星 / 新世界`（上游硬编码两名照搬【报告 §2】）。
3. **关**：✕ 钮 / 遮罩点击 / ESC（宿主栈口径，A2）；关闭 ⇒ 游戏状态**零变化**（面板不写档）。
4. **栈纪律**：在 `#/map?slot=N&map=…` 上弹层，**不改 URL、不进历史**；传送发生时才经 `gotoMap(…, pushHist)`（`AGENTS.md §3` 战斗回图带槽纪律不变）。

### 3.2 块表与渲染（WM2）

- 内容表 = 报告 §3 两张表**逐行照搬**（37 行：页 / 组 / mapId / 显示名 / 目标图名）；**数据文件 = 手写静态表**（生成物纪律不适用：上游本就手摆，无 XML 源）。
- **显示名取一通道**（修报告 A3/A3′ 双通道各漏一半：目标行为 = **不照搬**）：页 0 氏族块用**块标题名**（飞翼氏族…），页 1 用**悬浮名**（传送仓…）；每块**一个中文名 + 目标图真名脚标**（`目标图名` 列，如 空港/火幻氏族主城）。
- **当前图高亮**：块 `mapId == session.currentMapId` ⇒ 标"在此"；不禁止再点（同图再点 = 重进，同上游 `ChangeScene` 行为【报告 §5.4】）。
- 版式【设计】：页 = 组标题（北域 / 南域 / 飞船舱 / 星球 / 太空站…按报告 §2.1 树）**分组宫格**；**不画热区坐标**（无美术资产，靠人眼无此维）；`swfOk` 两路（SWF 图与 JS 回退图）**行为一致** —— 面板是 DOM 层，与画面通路无关。

### 3.3 传送链（WM3）

1. 点块 ⇒ **同一台** `resolve→run` 机的出口形状：发 `teleport{mapId}` intent（与光口/NPC/对话出路**同 sink**，`mapScene.js makeRunCtx.teleport`，MB5 已落）。
2. `decideTeleport(mapId)`：`0 ⇒ notOpen` ⇒ **弹提示盒"地图暂未开放"**（A3 既有 `openHintbox`；上游靠 Hintbox【报告 §5.1】，我们保留同等可观察行为 ⇒ **WMQ1**）；非 0 ⇒ `gotoMap(String(mapId), true)`（现场解析、不缓存，§4.9）。
3. 面板在传送执行**前关闭**（同 MB6 对话浮层"teleport 执行前撤浮层"口径）。
4. **不做**：上游 `50000 ⇒ mod_home 活动查表`（M5 TPQ3 已决"不实现查表"；`50000` 本就不在 37 块表内，无碰撞）；**不做**：Mod 面板分支（§1）。

### 3.4 不变量

- **WM1** 面板零写状态：开/关/翻页不产生落盘（Save 面只在传送换图时按既有链走）。
- **WM2** 块表是**唯一内容真值**：行数据以报告 §3 为准，改表先改报告/本份，**不许**运行时"从地图数据里现编目的地"（上游没有自动块表；`maps.json` 全 272 图 ≠ 目的地集合）。
- **WM3** 传送只经 `teleport` sink 一条链：面板**不直接**碰 `gotoMap`/`location.hash`（依赖方向 View→M5 决议，不旁路）。
- **WM4** L4 自绘、零新素材、零第三方：与 A2/A2b/B3/MB6 同族的**围栏再扩一格**（`AGENTS.md §4` 第 11/12 条先例），**不碰 `MapRunner.as`、不重编译 AS3**；正式美术仍归 A 组。

3. 页 1 点「传送仓」(10001) ⇒ 关面板 + 换图到飞船舱；HUD 图名横幅变；
4. 页 1 点「火山星」(10015) ⇒ 落火山星山脚下出生点；
5. 页 0 点「神醚氏族」(0) ⇒ **提示盒"地图暂未开放"**、面板不闪退；
