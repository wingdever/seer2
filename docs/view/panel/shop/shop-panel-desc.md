# 商店面板 · 版面正本（重启线 U·商店支）

> 本文件是**版面/排版权威**，由人类手测后回填（像素、配色、间距以人手实测为准）。
> 设计 = shop-design.md 3/5；实现 = shop-impl.md 5。本批先按 rbi-*（道具背包）同款近似落地，不追求逐像素。

## 容器与分区（与 rbi-* 同族）

- 容器 .rb-shop-box：left 120 / top 50 / w 720 / h 430，深底 #0e1626，圆角描边。
- 头：标题（黄，左）、货币（蓝，右，◈/✦ 前缀）、关闭（✕，红底，右）。
- 类型 tab 行：8 钮横排，选中黄边。
- 购买/出售切换：头下两钮，选中黄边。
- 列表：左 300px 网格（色块 tile + 名称 + 价格/持有）。
- 详情：右区（名称/类型/价格/持有/限购余量 + 说明 + 效果 + 步进器 + 购买/出售钮）。
- 底部 note 行：提示文案（黄）。

## 待人手测回填

1. 各 tab 商品数量与排序是否与预期一致。
2. 价格/货币符号显示是否正确（◈ 赛尔豆 / ✦ 星钻 / ×N 道具名）。
3. 图标现已经 Ruffle 渲染 /swf/item/icon/{resId}.swf，缺失/出错退回色块 tile（当前 = typeRaw 哈希色）。本快照仅 1.swf 资产 ⇒ 多数仍是 tile，补全图标集后才会全亮。
4. 步进器、禁用态（货币不足/限购满/持有不足）的视觉是否清晰。
5. 关闭后是否无残留层、再次打开是否正常。
