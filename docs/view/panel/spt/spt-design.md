## 0. 一句话目标

**在 `#/map` 点底栏 SPT 钮（或 NPC `openPanel SPTBoss[page=N]` / 活动 linkId）⇒ 弹一台自绘"三页大陆分布图"：北半球 9 只 / 南半球 3 只 / 派诺星系 6 只 boss（报告 §3 十八行表逐行照搬）画在各自线稿摆位上，点 = 发 `teleport{mapId}` 走既有决议机；面板零写档、零战斗规则。**

**SPT 面板解决的是"去哪找 boss"**；打不打得赢、`mode=3` 规则怎么写，是点击传送**之后**那张图上的事（MB7 链，已在）。

## 3. 目标行为（真值）

### 3.1 面板生命周期（SP1）

1. **开**：`#/map` 内点底栏 `spt` 钮 ⇒ `host.openPanel('rb-spt', …)`（A2）；**初始页 = 当前图按上游规则算**（§3.2）。
2. **翻页**：页签三钮 `北半球 / 南半球 / 派诺星系` 互斥显隐（同上游 SetPage，无动画）。
3. **关**：✕ / 遮罩（**同族先例：`worldmap`/`minimap`/`dex` 一律无 ESC、宿主 `host.js` 也不提供** ⇒ 本面板不承诺 ESC，见 impl §7 as-built SPB8）；关闭 ⇒ **游戏状态零变化**（SP1 零写档）。
4. **栈纪律**：弹层**不改 URL、不进历史**；传送发生时才经 `gotoMap(…, pushHist)`（`AGENTS.md §3` 战斗回图带槽纪律不变）。

### 3.2 初始页（SP2）【设计】= 照搬上游规则 + 越界夹紧

- 规则照搬：`page = worldId + 1`；`page ≤ 1 ⇒ (category ≤ 10 ? 0 : 1)`（桥已有同源件：`game/logic/map/parse-map.js:297` 的 `worldId`、`M.unity.category`；`worldId` 的 mod 分支差异**不移植**——我们的会话没有 mod 图）。
- **A2 维持为"可疑项"**【实测订正】：`category=100` = **要塞/门**（`81` 英格瓦要塞、`82` 经验之门…HUD 要塞钮链可达），按上游规则开面板落**南半球页**（物理上英格瓦在阿卡迪亚北）；`category=101–105` 飞船舱落**派诺页**。处置 = **SPQ3**（建议 A = 照搬——初始页只是缺省页、页签一键可切，不改判据；把手测"要塞内开板落在哪页"列观察项）。
- **订正 A5（越界）**：`page ∉ [0,3)` ⇒ **夹紧到最近合法页**（`[page=9] ⇒ 页 2；[page=−3] ⇒ 页 0`），**不出白板**。理由：白板 = 上游 bug（点了没画面），不照搬（决议 ②）。⇒ **SPQ4**。
- **订正 A6（非法参数）**：`[page=abc]`/缺失 ⇒ **按 §3.2 初始页规则走**，不抛（决议 ②同口径）。⇒ **SPQ4**。

### 3.3 块表与渲染（SP3）

- 内容表 = 报告 §3 三张表**逐行照搬**成静态数据文件（18 行：page / bossId / 宠名 / mapId / 目标图名 / 摆位 / 尺寸）；**改表先改报告/本份**，不许运行时从地图数据现编（同 WM2 纪律）。
- **头像 = `petIconUrl(bossId)`**（`_kit.js:46` 既有通道，18/18 在盘【报告 §3】）；缺图防御分支 = 画占位圆点 + `logLine`，**不伪造**（上游 A4 的 Empty.png 语义 = 同族先例 §4.14"缺图退占位"）。
- **点击 ⇒ 单发传送**（**修 A1**）：一律用表值 `mapId`，烘死值**不读**。⇒ 目标行为拍板 = **SPQ2**。
- **目标图待接线者如实提示**【设计】：18 张目标图里 **`530`（黑岩旋梯）、`910`（神风祭台）、`1290`（超源氏族主城）** 属**待接线清单**（`tools/map-audit.mjs` 口径：`530/910/1290` 在 `unreferenced=154` 里，尚无经我们链验证的通行记录）。点它们 = **照发 teleport 决议**（M5 六入口不设门禁、报告 §5"零门禁"照搬），**是否落成 = `decideTeleport` 的既有语义**（`notOpen ⇒ logLine`）；**面板不许**自造"未开放"置灰（上游无此态，SPQ5 记一笔人测观察）。
- **悬浮名**：hover ⇒ 提示盒出**宠名 + 目标图名**（上游只有宠名【报告 §2.2】；加目标图名 = 我们的可读性增强，零新逻辑）；常驻小名牌**不画**（同上游）。
- **版式（SPQ1）**：推荐 = **复刻线稿摆位**——bg 三张 PNG 已在 `Assets/Resources/Panels/SPTBoss/Sprites/`（520/524/线路 + 背景 1935×1158）、18 组摆位坐标已实测【报告 §3】，绝对定位落 `#800×500` DOM 盒；Unity 中心锚 y 向上 ⇒ CSS 换算 `cx = 400 + (父x+按钮x)`、`cy = 250 − (页偏移y + 父y + 按钮y)`（**偏移 = 人眼校**，`flipY`/`NPC_ANCHOR` 同族常量，§4.10 口径）。

### 3.4 传送链（SP4′，沿用 WM3 形状）

1. 点 boss ⇒ `runTeleport(mapId)`（**同一台** `resolve→run` 机，`mapScene.js:274`，与光口/世界地图/小地图/对话出路同 sink）。
2. 面板在传送执行**前关闭**（同 WM3.3 / MB6 撤浮层口径）。
3. **不做**：门禁/解锁校验（上游零门禁【报告 §5】，同 worldmap A11 照搬先例）。

### 3.5 不变量

- **SP1** 面板零写状态：开/关/翻页/悬浮不产生落盘。
- **SP2** 初始页规则只读 `M.unity`（桥的既有列），**不回读 XML**。
- **SP3** 18 行表 = **唯一内容真值**（静态数据文件）。
- **SP4** L4 自绘、**零新素材、零第三方**（线稿/头像全在盘）；**不碰 `MapRunner.as`、不重编译 AS3**；正式像素美术仍归 A 组口径（§4.11/§4.12 先例的再扩一格，见 §9 围栏登记）。

## 4. 落点与分层（预给 impl 的框，细节归 impl）

- **L4** `game/app/view/spt/`：`index.js`（装配口 `create(container, opts)`）+ `sptPanel.js`（DOM 自绘）+ `bosses.js`（SP3 静态表）——目录形状照 `view/worldmap/` 先例。
- **L4 接线三件**：① `restartHudView.js:77` `spt` 钮 ⇒ `handler:'onSpt'` + `mapScene.js` 注入 `openRestartSPT`；② `handlePanelLink`（`mapScene.js:321`）加 `SPTBoss` 分支（`ACT_UNBUILT` **摘除** `'SPTBoss'`，名单仍全仓唯一）；③ openPanel sink（`mapScene.js:1118`）加 `/SPTBoss/` 分支 + `page` 参数解析（复用 `parseShopArgs` 同形剥法）。
- **零新 L0/L1**：传送复用 `runTeleport`；宿主复用 `panels/host.js`；头像复用 `_kit.petIconUrl`；`ui.css` 加 `rb-spt-*` 一族。
